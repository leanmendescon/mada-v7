# MADA V7

## Como rodar

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Crie um arquivo `.env.local` com sua chave Gemini:
   ```bash
   GEMINI_API_KEY=sua_chave_aqui
   ```
3. Rode o app:
   ```bash
   npm run dev
   ```
4. Abra:
   ```bash
   http://localhost:3000
   ```

Se você não preencher a chave, o app usa um gerador local de landing page para funcionar sem erro.
